## Keputusan agen
- Endpoint public key butuh akses aktif (bukan hanya login): konsisten dengan endpoint lain yang memakai `requireActiveAccess`, dan tanpa akses tidak ada alasan berlangganan.
- Tombol "Aktifkan pengingat" tanpa izin tapi dengan `granted` tidak meminta izin lagi; hanya membuat langganan.
- Kartu dashboard "Atur wilayah" tidak lagi bertuliskan "Segera tersedia"; kini tautan ke `/settings#wilayah`.
- Bedtime di UI disembunyikan berdasarkan `layer.mode` (live), bukan membaca NODE_ENV di browser.

## Batasan dan sisa
- Logout belum membatalkan langganan push di browser. Baris server tetap aktif sampai dihapus dari Pengaturan atau dinonaktifkan oleh push service (404/410). Akun lain di browser yang sama punya kunci localStorage sendiri, jadi tidak keliru menampilkan "aktif", tetapi notifikasi untuk akun lama masih bisa tiba. Usul: unsubscribe saat logout (sesi berikutnya).
- VAPID produksi belum diisi (`VAPID_SUBJECT`, `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`). Sampai diisi, UI menampilkan "Pengingat belum tersedia."
- Pengingat tidur menunggu bank pesan owner.

## Cara uji manual di HP (setelah VAPID produksi terisi dan worker jalan)
Android Chrome:
1. Buka apps.munajaapp.com, masuk, buka Pengaturan, bagian Notifikasi.
2. Ketuk "Aktifkan pengingat", pilih Izinkan. Status berubah jadi "Pengingat aktif di perangkat ini."
3. Cek baris di tabel `push_subscriptions` (is_active true) dan kartu dashboard hilang.
4. Picu pengiriman (jalankan job dispatcher, atau buat `notification_jobs` tahajud dengan `scheduled_at` sekarang). Notifikasi tampil dengan ikon Munajaa. Ketuk: app terbuka di `/worship/session`.
5. Tolak izin di langkah 2 pada percobaan lain: teks cara membuka izin tampil, tombol hilang.
6. Ketuk "Matikan pengingat": baris server nonaktif/terhapus, tombol kembali.

iPhone (iOS 16.4 atau lebih baru):
1. Di Safari tab biasa: Pengaturan > Notifikasi menampilkan "Pasang Munajaa di layar utama dulu, lalu aktifkan pengingat" dan panduan.
2. Tambah ke Layar Utama, buka dari ikon, ulangi langkah Android 1 sampai 4.
3. Bila ditolak: iPhone Pengaturan > Notifikasi > Munajaa > Izinkan Notifikasi.
